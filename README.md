# ✦ Universitas Aeternum
### *Scientia Sub Stellis — Knowledge Beneath the Stars*

An immersive interactive university inspired by **Royal Cosmic Fantasy**, celestial observatories, and dark luxury aesthetics.

Universitas Aeternum is a personal digital learning universe that brings multiple independent learning academies together in one interactive cosmic environment.

Explore the celestial system, enter different academies, and build knowledge across multiple disciplines.

---

## 🌌 Project Overview

Universitas Aeternum transforms the traditional learning dashboard into an interactive celestial university.

The main interface features an astronomical observatory where each planet represents a gateway to a dedicated learning environment.

**Design Philosophy**
- Royal Cosmic Fantasy
- Celestial Universe
- Dark Luxury
- Astronomical Exploration
- Interactive Learning Experience

**Visual Identity**
- Deep cosmic navy and midnight blue
- Royal violet and celestial gold
- Animated astronomical elements
- Elegant typography and ornamental details
- Immersive planetary navigation

## 🎓 Learning Academies

The university integrates several independent educational environments.

### 🌍 Language Learning

- English Learning Studio — CEFR-based English learning.
- Mandarin HSK Academy — HSK 1–6 learning environment.
- Hanyu Jiaocheng Mastery Academy — 汉语教程 1A–3B.
- Japanese Learning Hub — Multiple Japanese learning pathways.
- Japanese Writing Mastery — Hiragana, Katakana, and introductory Kanji.

### 💼 Career & Professional Skills

- JOB READY — Career preparation and employment skills.
- Excel Mastery Academy — Microsoft Excel learning.
- Office Productivity Academy — Microsoft Word and PowerPoint.

### 🎨 Creative Education

- Graphic Design Academy — Professional graphic design education.

### 🤖 Technology & Innovation

- Artificial Intelligence Academy — AI education and practical learning.

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `Universitas_Aeternum_Celestial_Cosmos_v5.html` in a modern web browser.
3. Explore the celestial observatory.
4. Select a planet to enter its corresponding academy.

No build process or package installation is required.

---

## 💾 Data & Compatibility

- Learning progress is stored locally by individual academy implementations where supported.
- Browser storage is device- and browser-specific.
- Clearing browser data may remove locally stored progress.
- Some external resources may require an internet connection.
